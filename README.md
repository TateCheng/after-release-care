# After Release — Does Care Follow?

A scroll-driven visual story about continuity of healthcare between prison and the community in the UK.

## Online site

https://tatecheng.github.io/after-release-care/

## Local development

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
```

The site is built with React, TypeScript, Vite and GSAP. Changes pushed to `main` are built and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

## Sources and assets

The narrative prototype is based on *Patient Perspectives: Prison Leavers CORE20PLUS5*. The consultation involved 135 people on probation. The characters are 2D sprites adapted from Kenney's CC0 Animated Characters Protagonists; see `CREDITS.md` for details.
