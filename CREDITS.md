The transparent PNG files in `public/characters/kenney/` are 2D derivative sprites rendered from Kenney's `characterMedium.fbx`. The standing pose uses the supplied idle animation. The eight walking poses were generated by articulating the same character skeleton because the mirrored run clip contained only a single pose.

All people in the story share this base model. Colour and scale communicate narrative roles; the model itself does not change. Kenney's CC0 licence permits these adaptations and does not require attribution.
